# Two causes, both consequences of what the release omits:
#
# 1. Evidence. These tests read the evidence packages, checkpoints, and
#    closeout receipts under artifacts/, which are in the archive deposit
#    rather than duplicated in a source repository.
# 2. Module layout. The provenance code content-addresses the original module
#    directories (multicase_fault_benchmark/, health_rssm/, data_v4/, data_v6/).
#    The public release renames those directories for readability, while the
#    provenance receipts record the original names, so the manifests are not
#    rewritten: rewriting them would make the code disagree with the receipts
#    it checks.
#
# The tests are skipped rather than removed so a reader can see what the full
# study checks. None is in scripts/portable_tests.txt, and none is run by either
# documented verification command.
#

# module that this release does not ship.
